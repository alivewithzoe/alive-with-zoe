# CLAUDE.md — How we work on the Alive with Zoë website

This file is read by Claude at the start of every session. It holds the working
rules, the business details, and a running list of everything Zoë has approved.

## Working rules (follow these every time)

1. **Ask before changing anything.** Before making any change, ask Zoë 3–5
   clarifying questions at a time, then wait for Zoë's answers before doing
   anything.
2. **One step at a time.** Only work on the single step Zoë asks for. Never
   change anything Zoë has already approved unless Zoë asks for that change.
3. **Plain, beginner-friendly words.** Explain everything simply. Avoid jargon,
   and if a technical word is needed, explain what it means.
4. **Show options for every design choice.** For any design decision (colors,
   fonts, layout, wording, images, etc.), show 2–3 options and let Zoë pick.
5. **Plain HTML and CSS only.** Build the site with plain HTML and CSS so it
   works on GitHub Pages. No frameworks, build tools, or anything that needs
   installing.
6. **Phones first.** Design for phone screens first, then make it look good on
   tablets and computers.
7. **Report after every change.** After each change, tell Zoë exactly what
   changed and exactly what to check on the live site.
8. **Keep "Decisions so far" up to date.** Every time Zoë approves something,
   add it to the "Decisions so far" section below.
